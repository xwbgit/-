# DAS-SentinelAgent 部署与使用说明书

## 1. 系统运行环境要求
- **操作系统**：Windows 10/11 / Linux (Ubuntu 20.04+, CentOS 7+) / macOS
- **Python 版本**：Python 3.10+ (推荐 Python 3.11 或 3.12/3.14)
- **网络需求**：真实目标巡检需要能访问已授权站点；内置靶场仅用于本地回归，生产模式不会自动启动。

---

## 2. 一键启动部署方法

### 方式 A：Windows 一键快速启动（推荐）
在项目根目录下，直接双击运行：
```cmd
start.bat
```
脚本会自动检查依赖并拉起主系统与 Web 控制台：`http://127.0.0.1:8000`。生产默认不启动内置靶场。

---

### 方式 B：命令行直接启动
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动系统（真实目标模式，仅拉起主控台）
python run.py
```

如需本地回归靶场，再显式开启：

```powershell
$env:ENABLE_BUILTIN_LAB="true"
python run.py
```

---

### 方式 C：Docker / Docker Compose 容器化部署
```bash
docker-compose up -d --build
```
启动后可通过浏览器访问 `http://localhost:8000`。

---

## 3. 核心功能操作指引

1. **态势总览**：打开 `http://127.0.0.1:8000`，填写已获授权的目标 URL 与授权域名后点击【开始巡检】；本地回归时可使用【填入内置示范靶场】。
2. **智能体控制台**：切换到【智能体控制台】，在输入框发送自然语言指令（如：*“对 http://127.0.0.1:8088 启动全量深度合规巡检”*），右侧可实时观察智能体的思维链（ReAct Trace）与工具编排。
3. **查看证据链与整改建议**：切换到【风险与证据链】，点击任意风险项右侧的【🔍 证据链】，即可查看请求/响应现场报文、脱敏掩码及代码级修复指南。
4. **导出报告**：在【巡检任务管理】中点击【📄 报告】，可在线查看专业安全报告，并支持一键打印/保存为标准 PDF 报告。
5. **基线对比**：在执行两次巡检后，进入【基线差异对比】，选择前次与本次任务，一键查看风险收敛趋势与修复闭环项。
6. **恒脑平台对接**：进入【恒脑平台对接】，可查看符合安恒恒脑标准的 OpenAPI 3.0 / Function Calling Schema 定义。

---

## 4. 自动化测试套件运行
在项目根目录运行 pytest 自动化测试：
```bash
python -m pytest tests/ -v -s
```
测试数量会随功能演进，应以 Pytest 当次输出为准。本地靶场的检测效果指标由版本化标注集计算，复现方法见 `docs/TEST_REPORT.md`。
